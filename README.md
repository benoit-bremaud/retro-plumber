# retro-plumber

A side-scrolling platformer for the browser: run, jump, stomp, break blocks and reach the flag.
Original character, levels, art and sound; tight, faithful-feeling platformer physics.

**Status:** design study (brick 0). No playable build yet.

- Game design: [docs/design/](docs/design/)
- Study: [docs/study/](docs/study/)
- Decisions: [docs/decisions/](docs/decisions/)
- Architecture (UML): [docs/architecture/](docs/architecture/)
- Log: [PROJECT_LOG.md](PROJECT_LOG.md)

Planned stack: TypeScript (strict), native Canvas 2D, Vite. Clean architecture (pure domain,
ports and adapters) and SOLID principles throughout.

`retro-plumber` is a codename. This project is not affiliated with, nor endorsed by, any console
publisher; it uses no third-party name, sprite, sound or level.
